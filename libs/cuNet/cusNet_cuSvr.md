##### cuNetClient 기능 
- cubl로 만들어진 서버  libcuo/cuNet.h  cuNetS를 상속받은 서버로 접속 한다. 
- 연결 정보 (계정 정보 및 기타 정보를 적용 할 수 있다. )  -- RAS 기능 설명  
- 지속적 연결 상태 유지 한다.  연결 50초 동안 5번 이상 연결 실패하면 연결 해제 된다.  
- 송수신중 오류로 실패하면 연결 해제 된다.

#### 데이터 전송 방식 

- 기본적으로 Req -> Ack 관계로 동작한다.  Pool 제외함 
- Pool 은 내부적올 작동함  (서버와 연결 상태 확인) 
- 텍스트, 스트럭처, 메모리, Json, XML, cuo 변환 스트링 객체의 전송을 지원한다.
