#### Cubl Cmd 

- Cubl 로 만들어진 프로그램 또는 시스템은 리눅스 또는 윈도우 콘솔에서  
    명령어를 통해 컨트롤이 가능하다. 
    - 네트워크 기능 
    - 암호키 생성 및 적용 기능 
    - 플러그인 동적 라이브러리 재 배포 기능  
    - 정보 확인 및 정보 변경 기능 
    - 분산 시스템 추가 및 분산 서버 설정 기능 
    - 시스템 운영 및 로그 분석 기능  
    - 스레드 및 프로세스 기능 
    - DB 연결 및 사용 
    - 시스템 병렬화 제어 기능 
    - 작업 요청 기능  
    - 테스트 기능
